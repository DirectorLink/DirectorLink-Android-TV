## DirectorLink · Android TV Notifications 1.0.1

A fix for Show Notification's **Send To: All TVs**, the command that shows a pop-up on every TV in the project, one copy of the driver per TV.

### File

| Driver in Composer | File |
|---|---|
| DirectorLink · Android TV Notifications | `DirectorLink-Android-TV.c4z` |

Check the download against `SHA256SUMS.txt`. Keep the file name exactly as it is: a browser's `(1).c4z` copy installs as a separate driver.

### Changes

- **Send To: All TVs** looks for the other copies under the file name the controller has for the driver, as well as under `DirectorLink-Android-TV.c4z`.
- A Show Notification from another copy is taken whichever way the controller hands it over.
- When no other copy is found, the log says what the controller listed and this copy's device number.

### Updating

Update the driver with **Driver → Add or Update Driver or Agent**: every copy in the project updates, and settings and programming stay. Requirements: Control4 OS 3.3.0 or newer, Composer Pro, a TV with Google TV or Android TV with **PiPup — TV Notifications** installed. Full steps: [directorlink.io/drivers/android-tv](https://directorlink.io/drivers/android-tv).

### Known issues

- **Send To: All TVs** was tested with two copies of the driver on one TV, with the controller's part played by the tests, not yet with several TVs on a Control4 controller. PiPup shows one pop-up at a time, so two copies on the same TV show one pop-up.
- **Only PiPup — TV Notifications** by Alexander Savin: other apps called PiPup take other requests and do not work with the driver.
